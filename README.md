# protect-DAG-BFT

블록체인 그리고 DAG 구조를 공부하며 Git에 관심을 가지다가 Git 자체만으로 메신저 역할을 하는 프로젝트를 보게 됐고, 새로운 연구를 진행하고자 한다.
기존에 학습해오던 방법은 서버를 두개 띄워두고 메시지가 어떻게 위조 및 변조 되는지에 관심가졌는데(욕설이나 언어를 마스킹하는 처리 기술이라던지)
Git 자체만으로 사용하는 기능들을 사용하여 메시지 공격과 방어 로직을 구현하게 된다면 DAG 구조에서 가졌던 난제들을 이해하는 것에 보탬이될까 싶어서 남겨둔다.
